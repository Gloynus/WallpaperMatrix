# Wallpaper Matrix 3.6.1

- Исправлено просвечивание статичных обоев и интерфейса через края символов и
  ореолы: D3D11 теперь сохраняет уже накопленный альфа-канал непрозрачного фона.
- Отключение Базы данных больше не очищает образ мгновенно. Только новые струи
  перестают поддерживать изображение и постепенно заменяют его обычным кодом.
- Ретрансляторы одного потока используют одну настоящую симуляцию даже при
  независимых настройках Базы данных; отдельные генераторы с одинаковым seed
  больше не создаются.
- При расширении холста текущие струи и проявленный образ переносятся в прежние
  физические координаты. Поверхность D3D11 не пересоздаётся, а новые области
  начинают заполняться без сброса уже работающих экранов.
- Схема устройств вывода стала в полтора раза выше; миниатюры, подписи и значки
  получили больше места, а индикатор потока перенесён вниз по центру.
- Имена дисплеев читаются из EDID, поэтому аппаратные коды наподобие `XMI27B2`
  заменяются понятными названиями Windows, например `Mi Monitor`. Основной экран
  получает номер 1.
- Пауза в играх теперь плавно замедляет движение до нуля за 0,7 секунды,
  полностью замораживает симуляцию и плавно возвращает установленную скорость
  после выхода из полноэкранного приложения.
- Самопроверка маршрутизации дополнена прямым переходом
  `Изолированный → Ретранслировать` и расширением общего холста с переносом
  текущего состояния.
