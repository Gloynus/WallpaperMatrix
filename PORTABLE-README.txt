WALLPAPER MATRIX 3.5.0 — ПЕРЕНОСИМЫЙ ВЫПУСК
================================================

ЗАПУСК

1. Полностью распакуйте ZIP-архив в любую папку.
2. Запустите WallpaperMatrix.exe.

Установка и отдельно установленный .NET не требуются. Приложение рассчитано
на Windows 10/11 x64. Вывод использует встроенные в Windows Direct3D 11
и DirectComposition; отдельно устанавливать графические библиотеки не нужно.

Windows 11 с включённым Smart App Control блокирует неподписанные приложения
без возможности разрешить один отдельный файл. Перед запуском откройте свойства
WallpaperMatrix.exe и проверьте наличие действительной цифровой подписи.
Старые и самостоятельно собранные версии могут оставаться неподписанными.

ХРАНЕНИЕ ДАННЫХ

Рядом с WallpaperMatrix.exe создаётся папка OperatorData:

    CurrentSettings.json — текущие параметры
    Playlists.json       — плейлисты изображений
    Diagnostics.log      — журнал диагностики
    Preset - ... .json   — глобальные пресеты

Распакуйте программу в обычную папку с правом записи. При обновлении замените
EXE в этой же папке: OperatorData останется на месте.

Программа не переносит и не удаляет данные прежних версий автоматически.

АТАКА СИСТЕМЫ

Синхронизированная заставка включается в отдельном блоке после «Базы данных».
Существующий код остаётся частью фонового рабочего стола, а поверх интерфейса
естественно натекают только новые струи текущего образа. Интерфейс не снимается
и не преобразуется в код: непокрытые области постепенно растворяются в фоне
живых обоев. Кнопка «Проверить атаку» запускает переход немедленно. Любой
реальный ввод возвращает интерфейс.

Если в Windows уже назначена другая системная заставка, отключите её либо
установите ей более длинную задержку, чтобы две заставки не запускались
одновременно.

1. Выберите «Выход» через зелёный значок M в области уведомлений.
2. Если включён автозапуск, сначала отключите «Запускать вместе с Windows»
   и нажмите «Применить».
3. Удалите папку с приложением.
