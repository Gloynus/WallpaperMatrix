# Wallpaper Matrix 3.3.5

## Непрерывный вход в «АТАКУ СИСТЕМЫ»

- Рабочий поток больше не приостанавливается при появлении поверхности
  заставки. Уже видимый код продолжает двигаться под прозрачным переходным
  слоем, а новые струи натекают поверх интерфейса.
- Ожидание композитора Direct3D 11 вынесено из общей блокировки сцены.
  Задержавшаяся передача одного кадра больше не может остановить симуляцию или
  второй вывод той же сцены.
- Общий список символов теперь публикуется в собственный стабильный буфер.
  Устранена гонка между построением следующего кадра и его передачей на GPU.

## Диагностика редких пауз

- В журнал добавлены записи о кадрах симуляции или D3D11, занявших больше
  120 мс. Записи ограничены по частоте и появляются только при реальной
  задержке; в них раздельно указаны этапы симуляции, загрузки сцены и ожидания
  композитора.
