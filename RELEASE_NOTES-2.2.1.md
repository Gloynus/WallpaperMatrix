# Wallpaper Matrix 2.2.1

## Исправления

- Вкладки Контуров снова переключаются мышью: восстановлена штатная фокусировка и добавлено явное назначение выбранного контейнера при нажатии.
- Сброс блока Часов больше не выключает часы.
- Сброс Базы данных больше не выключает режим изображений.
- Сброс Базы данных не изменяет плейлисты, их состав, порядок, галочки или текущий выбор.
- Групповые сбросы по-прежнему меняют только черновик внутренних параметров.
