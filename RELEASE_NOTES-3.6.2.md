# Wallpaper Matrix 3.6.2

- Номера в «Устройствах вывода» получаются из активных путей CCD Windows, а
  названия — из системного устройства и EDID.
- Миниатюры мониторов получили более крупные режимные значки, увеличенный текст,
  отдельные зоны содержимого и нижнюю центральную лампу состояния.
- Ретранслятор может копировать конкретную видимую часть расширенного потока.
  Цепочка по-прежнему вычисляется одним корневым генератором без рекурсивной
  симуляции.
- Аналогичная адресация доступна Базе данных: выбранная часть расширенного
  образа больше не схлопывается к корневому монитору.
- Перестройка маршрута публикует восстановленную сцену только после подключения
  общего потока, поэтому смена режима Базы данных не создаёт промежуточного
  кадра с иной яркостью.
- АТАКА СИСТЕМЫ выводит уже существующие струи вторым согласованным проходом.
  Они остаются за интерфейсом в начале и плавно входят в заставку по мере
  захвата, сохраняя устойчивые света изображения на расширенных экранах.
- Проверки маршрутизации, D3D11-шейдеров, бесшовного переключения и
  двенадцатисекундного жизненного цикла АТАКИ проходят без ошибок.
