# Wallpaper Matrix 2.2.3

## Исправления рабочего стола

- Полностью удалён небезопасный резервный вывод через `Progman`. Версия 2.2.2 могла разместить невидимое окно под статичными обоями и при этом заблокировать рамку выделения и значки рабочего стола.
- Окно рендера создаётся скрытым и становится видимым только после успешного подключения к отдельному `WorkerW`. Ошибка обнаружения слоя больше не затрагивает ввод рабочего стола.
- После запросов Explorer приложение ждёт появления `WorkerW` до 2,6 секунды, что учитывает его отложенное создание на некоторых версиях Windows 10/11.
- Поиск понимает вложенное размещение `SHELLDLL_DefView`, но исключает одноимённые элементы обычных окон Проводника.
- Допустимым признаётся только пустой `WorkerW`, который покрывает весь виртуальный рабочий стол. Маленькие служебные окна Explorer больше не могут быть выбраны как поверхность обоев.
- При остановке выполняется синхронная перерисовка `Progman`, `WorkerW`, `SHELLDLL_DefView` и корневого окна рабочего стола. Текущая системная картинка повторно применяется без записи новых пользовательских настроек.
- Диагностика фиксирует результат каждого классического и современного запроса `WorkerW`, а также компактную топологию только относящихся к рабочему столу окон.

## Рекомендация

Версию 2.2.2 использовать не следует. Она оставлена только как предыдущий диагностический выпуск.
