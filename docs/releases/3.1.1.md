# Wallpaper Matrix 3.1.1

## Сигнал по умолчанию

- Заводской диапазон яркости струй изменён на `4–16` ступеней.
- Существующие пользовательские настройки и глобальные пресеты не перезаписываются.

## Память

- Проценты Памяти теперь однозначно связаны со временем прохождения полной высоты экрана, а не с длиной конкретного шлейфа.
- `0%` гасит символ сразу после импульса; `100%` гасит его за одну условную высоту; `200%` одну высоту удерживает и ещё одну гасит.
- Иллюстрация калибратора использует ту же формулу, что и поток.
- Подсказки переписаны с примерами и объяснением роли кривой.

## Проявление образа

- «Стабильность света» удерживает любой видимый целевой уровень ровно на выбранную долю Цикла образа; прежнее скрытое ослабление для полутонов удалено.
- «Устойчивость тени» имеет прямую шкалу: `0%` — обычное угасание, `50%` — вдвое быстрее, `100%` — немедленно до целевого уровня.
- Оба параметра фиксируются в момент появления символа. Изменение ползунков больше не пересчитывает уже существующий код.
- Видимый образный уровень продолжает жить по Стабильности даже после полного угасания исходного символа шлейфа.

## Интерфейс

- У поля «Цикл образа» удалена вторая, дублирующая кнопка сброса.
