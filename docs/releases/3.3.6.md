# Wallpaper Matrix 3.3.6

## Подготовка доверенного выпуска

- Добавлены явные метаданные продукта, автора, версии, репозитория и лицензии
  для проверки будущей подписи Authenticode.
- Зависимости NuGet закреплены lock-файлом; выпускная сборка использует только
  зафиксированные версии.
- Добавлены политика подписи, политика конфиденциальности, роли выпуска и
  инструкция проверки подписи.
- Сценарий сборки принимает отдельный выходной каталог, автоматически выбирает
  примечания текущей версии и не смешивает выпуск с пользовательским
  `OperatorData`.
- Официальная CI-сборка формирует чистый переносимый ZIP и его SHA-256.

Версия является кандидатом на первую доверенно подписанную публикацию. Наличие
подписи определяется только свойствами конкретного `WallpaperMatrix.exe`;
локальные сборки автоматически официальными не считаются.

## Code signing policy

Free code signing provided by
[SignPath.io](https://about.signpath.io/), certificate by
[SignPath Foundation](https://signpath.org/).

До одобрения проекта SignPath опубликованный кандидат остаётся неподписанным и
может блокироваться Smart App Control. После подключения сервиса официальный
статус конкретного файла подтверждается только действительной подписью
Authenticode в свойствах `WallpaperMatrix.exe`.
