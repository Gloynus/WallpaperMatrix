# Wallpaper Matrix 3.9.1

## Общий каталог плейлистов

- Плейлисты теперь являются единым каталогом оператора для всех устройств
  вывода.
- Изолированная база данных хранит только выбранный для своего экрана
  плейлист; его строки, порядок и доступность общие с остальными экранами.
- Старый файл плейлистов автоматически переносится в новую схему: каталоги,
  которые ранее были сохранены в профилях отдельных мониторов, объединяются
  без потери уникальных плейлистов.
