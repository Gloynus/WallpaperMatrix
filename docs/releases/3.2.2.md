# Wallpaper Matrix 3.2.2

## Раздельная отмена и скрытие

- Кнопка «Отменить» возвращает последние применённые параметры, но больше не сворачивает операторскую консоль.
- После отката черновик исчезает, кнопка «Отменить» скрывается, а «Применить» автоматически становится кнопкой «Скрыть».
- Крестик в заголовке сохраняет составное действие: отменяет неприменённые изменения и сразу скрывает консоль.
- Закрытие окна системной командой использует то же безопасное поведение, что и крестик.
