# Wallpaper Matrix 3.7.5

- Отключённые устройства больше не предлагаются источниками ретрансляции или
  расширения ни в выпадающих списках, ни в контекстном меню. Устройство с
  отключённой только Базой данных остаётся доступным источником Потока.
- На левом краю операторской консоли появилась компактная навигация по основным
  блокам. Закладки раскрываются при наведении, подсвечивают текущий раздел и
  плавно прокручивают форму к его реальному положению после любых изменений
  профиля монитора или состояния блоков.
- Названия вкладок Калибратора потока увеличены ещё на один пункт.
- Поля **ОТ** и **ДО** на вкладках Скорости, Объёма, Сигнала, Фильтрации и
  Памяти получили общую координатную сетку и больше не смещаются при
  переключении.
- Исправлена нижняя граница бегунка вертикального скроллбара, в том числе при
  дробном масштабировании интерфейса Windows.
