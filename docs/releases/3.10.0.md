# Wallpaper Matrix 3.10.0

## Размещение образов по осям

- Настройка масштаба перенесена из блока «Вывод» в сам плейлист.
- Переключатели «Заполнить: по горизонтали / по вертикали» дают четыре
  пропорциональных режима: вписать целиком, привязать к ширине, привязать к
  высоте или заполнить всю область с обрезкой краёв.
- Во всех режимах используется единый коэффициент масштаба для обеих осей:
  геометрические пропорции исходного изображения никогда не искажаются.
- Каждый плейлист запоминает собственное размещение и сохраняет его в общем
  каталоге плейлистов.
- Старые «Вписать/Заполнить» автоматически преобразуются в соответствующие
  комбинации новых переключателей.

## Сборка

- Целевая среда `win-x64` закреплена в проекте, поэтому обычная и переносимая
  сборки используют один стабильный lock-файл зависимостей.
