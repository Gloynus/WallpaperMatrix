# Wallpaper Matrix 3.10.3

## Повторный запуск

- Запуск `WallpaperMatrix.exe`, когда приложение уже работает, больше не
  показывает информационное сообщение.
- Новый процесс передаёт существующему экземпляру команду открытия панели и
  сразу завершается.
- Уже открытая или свёрнутая панель выводится на передний план без запуска
  второго рендера и без перезапуска потока.
- Межпроцессная команда передаётся локальным системным сигналом текущего сеанса
  Windows; дополнительный фоновый процесс или сетевой канал не создаётся.
