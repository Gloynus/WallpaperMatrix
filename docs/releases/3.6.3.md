# Wallpaper Matrix 3.6.3

- АТАКА СИСТЕМЫ снова строит образ новыми струями: готовые клетки изображения рабочего стола не поднимаются поверх интерфейса.
- Обычный код прежнего потока подключается лишь в заключительной части перехода, сохраняя непрерывность движения без преждевременного появления готового образа.
- Смена источника БАЗЫ ДАННЫХ сохраняет существующую сцену и её D3D11-ресурсы, если топология потока не изменилась. Уже опубликованные символы не пересобираются из-за одной только маршрутизации базы.
- Значки режимов устройств вывода заменены векторными: поток расположен слева, база данных справа; ретрансляция и расширение имеют разные формы.
- Диагностика больше не называет CCD-приоритет системным номером монитора. Windows не предоставляет номер, нарисованный приложением «Параметры», как документированное свойство дисплея.
