# Wallpaper Matrix 1.5

## Смена масштаба

- Размер знака применяется после паузы в 650 мс на выбранном значении.
- Текущий поток переносится в новую сетку вместо полной генерации заново.
- Сохраняются яркость, возраст, знак, Память, Импульс и фосфорное свечение существующих ячеек.
- Головы струй сохраняют относительное положение на экране, экранную скорость, длину и точку завершения.
- При укрупнении конфликтующие ячейки объединяются по наиболее заметному состоянию; при повышении детализации проявленный образ пересэмплируется в более частую сетку.
- Вторая симуляция и постоянное удвоение нагрузки не используются.

## Плейлисты

- Создание и удаление плейлиста перенесены к выпадающему списку.
- Сохранение находится справа от поля названия.
- Добавление файлов и папок обозначено составными значками.
- Команды под таблицей сокращены до трёх групп по три действия.
- Добавлены снятие выделения и двунаправленная сортировка по времени изменения файла.
- Сортировки «А–Я / Я–А» и «Новее / Старее» меняют направление повторным нажатием.
- Контекстное меню получило собственный матричный шаблон без системного поля значков и белых контуров.
- Щелчок правой кнопкой по строке сначала делает её активной.

## Анализ данных

- «Подготовка образа» и «Структура сигнала» находятся в одной строке.
- Обе колонки ручного анализа содержат по три одинаково расположенных регулятора.
- Выбор структуры приглушён у готовых профилей и активируется для ручной проявки.
