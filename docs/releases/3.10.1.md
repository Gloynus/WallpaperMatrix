# Wallpaper Matrix 3.10.1

## Размещение плейлиста в изолированных базах

- Один каталог плейлистов по-прежнему используется всеми устройствами вывода.
- Переключатели «Заполнить: по горизонтали / по вертикали» теперь сохраняются
  отдельно для каждой изолированной Базы данных и каждого плейлиста.
- Один плейлист можно выводить по ширине на одном экране и по высоте на другом,
  не создавая копий списка и не искажая пропорции изображений.
- Ретрансляция и расширение получают размещение от исходной Базы данных.

## Интерфейс и сохранение

- Изменение любого из двух переключателей сразу включает состояние
  неприменённых правок и показывает кнопки «ОТМЕНИТЬ» и «ПРИМЕНИТЬ».
- Возврат переключателей к сохранённой комбинации снова переводит кнопку в
  состояние «СКРЫТЬ».
- Дискета плейлиста сохраняет общий каталог, активные плейлисты и параметры
  размещения всех изолированных Баз данных одной операцией.
- Кнопка «ПРИМЕНИТЬ» сохраняет те же данные вместе с остальными настройками.

## Надёжность

- Формат `OperatorData\Playlists.json` обновлён без дублирования изображений по
  мониторам: в профилях хранятся только лёгкие параметры представления.
- Встроенная самопроверка подтверждает независимые режимы одного плейлиста на
  двух экранах, обнаружение изменения и корректное снятие признака черновика
  после возврата к сохранённым значениям.
