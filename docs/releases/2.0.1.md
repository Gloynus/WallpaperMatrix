# Wallpaper Matrix 2.0.1

## Исчерпывающая жирность

- Шкала расширена до `−100…100%`.
- `0%` теперь строго соответствует обычному весу выбранного системного шрифта без искусственной обработки.
- Отрицательные значения сочетают лёгкие системные веса с контролируемым утончением пиксельного контура.
- Положительные значения доходят до системного веса `900` и дополнительно расширяют растр, поэтому верхняя часть шкалы стала значительно выразительнее.
- Существующие значения версии 2.0 сохраняют своё положение; сброс одного параметра «Жирность» возвращает настоящий ноль.

## Геометрия и интерфейс

- Подтверждена нейтральная точка высоты: `0%` использует исходную высоту шрифта без предварительного сжатия.
- Пояснение управления точками кривой перенесено непосредственно под калибратор и над настройками шрифта.
- Цветовая шкала получила собственный прозрачный шаблон: системная белая горизонтальная дорожка больше не перекрывает спектр.
