# Wallpaper Matrix 3.7.1

- `Playlists.json` перечитывается без перезапуска при открытии списка
  плейлистов и при переключении Базы данных. Чтение выполняется только после
  фактического изменения файла, поэтому обычное открытие списка не уничтожает
  несохранённый редактор.
- Исправлено перетаскивание виртуального монитора при любом масштабе и
  смещении карты: карточка больше не уходит от курсора.
- Поля разрешения виртуального монитора снова позволяют выбирать готовые
  значения и вводить произвольные размеры вручную.
- Все галочки операторской консоли оформлены едиными переключателями в стиле
  интерфейса.
- У параметров «Бездействие» и «Захват системы» удалены оставшиеся внешние
  кнопки сброса: у каждого числового поля теперь ровно один встроенный сброс.
- Диагностика перенесена внутрь блока «Устройства вывода» и занимает одну
  компактную строку над картой мониторов.
