# Wallpaper Matrix 2.2.2

## Исправления совместимости рабочего стола

- Устранено ложное переподключение вывода сразу после запуска: уведомление Windows теперь приводит к пересборке окон только при реальном изменении состава, размеров или расположения экранов.
- Пересборка при настоящем изменении конфигурации мониторов больше не оставляет `WorkerW` скрытым и пустым, поэтому Explorer не успевает уничтожить слой до подключения новых окон.
- Запуск считается успешным только после проверки `SetParent`, геометрии окна, первого OpenGL-кадра и фактической видимости поверхности рабочего стола.
- Если конкретная версия Explorer создаёт, но не показывает отдельный `WorkerW`, приложение автоматически пробует совместимый резервный вывод через `Progman`.
- Журнал теперь содержит дескрипторы, классы, координаты, видимость и родительские связи слоя Explorer и каждого окна вывода. Ошибка встраивания больше не маскируется сообщением «ВЫВОД АКТИВЕН».
- Неожиданное уничтожение окна вывода со стороны Explorer определяется как ошибка и отображается в состоянии приложения.
