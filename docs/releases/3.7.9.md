# Wallpaper Matrix 3.7.9

- Состояние строк плейлиста синхронизируется в обе стороны: восстановленный
  файл возвращает стандартное оформление сразу после успешного чтения.
- Первый запуск приложения, ручное возобновление после «Стоп» и восстановление
  вывода используют единый путь инициализации с системными обоями как нулевым
  образом Базы данных.
- Каждый новый поток снова начинается естественным наплывом поверх статичных
  обоев, а не с ранее активного изображения плейлиста.
