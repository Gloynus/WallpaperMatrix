# Wallpaper Matrix 3.3.3

## АТАКА СИСТЕМЫ

- Переход использует два прохода одной общей сцены: уже существовавший поток
  продолжает двигаться под захваченным интерфейсом, а новые струи натекают
  поверх него. Вторая симуляция и отдельная копия данных не создаются.
- Тела символов атакующего слоя стали непрозрачными. Яркость передаётся цветом
  знака, поэтому внутри его штрихов больше не просвечивают остатки интерфейса.
- Полупрозрачный ореол остаётся частью захвата, но плавно исчезает к завершению
  перехода и не загрязняет готовую заставку.
- При переходе к образу плейлиста уже проявившиеся символы больше не меняют
  яркость одновременно. Отпечаток сохраняется только в существующих струях,
  а новые струи естественно заменяют его следующим образом.
- Если активного плейлиста нет, отпечаток интерфейса удерживается ещё один
  интервал «Захвата системы», после чего новые струи перестают его повторять
  и постепенно стирают остаток до чистого потока.
