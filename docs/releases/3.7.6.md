# Wallpaper Matrix 3.7.6

- Скроллбары переработаны на уровне единого шаблона: вертикальный и
  горизонтальный бегунки получили собственные геометрические ограничения,
  нижние компенсирующие отступы удалены, а холст мониторов больше не содержит
  второго конкурирующего шаблона. Плашка теперь рисуется цельной капсулой без
  постоянного отсечения части собственной формы.
- Начальная ширина операторской консоли явно закреплена на `740 px`; после
  открытия окно по-прежнему свободно изменяется пользователем.
- Боковая рейка теперь постоянно показывает вертикальные названия разделов.
  Наведение подсвечивает закладку, а активной считается секция, занимающая
  наибольшую часть видимой области формы.
- В блок Атаки системы добавлено напоминание о таймерах Windows со ссылками на
  параметры отключения экрана и системной заставки.
- Контекстное меню мониторчика получило общий заголовок с названием устройства
  над обеими колонками маршрутизации.
