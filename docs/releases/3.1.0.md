# Wallpaper Matrix 3.1.0

## Расширенный ручной диапазон

- Ползунки и изменение колёсиком сохраняют удобные границы: скорость `1–100%/с`, цикл образа `3–600 с`.
- Ручной ввод скорости допускает значения до `1000%` высоты экрана в секунду.
- Ручной ввод цикла образа допускает значения от `0,1 с`.
- Абсолютные пределы проверяются повторно в модели настроек, поэтому повреждённый пресет или отредактированный JSON не может передать симуляции бесконечность либо неограниченное значение.

## Безопасность быстрого цикла

- Следующая смена не ставится в очередь, пока предыдущий образ ещё готовится.
- Добавлен ограниченный LRU-кэш на 10 декодированных источников; подготовленные тональные карты по-прежнему имеют отдельный ограниченный кэш.
- Кэшированные смены используют общий пул рабочих потоков вместо создания нового системного потока для каждого изображения.
- Частота служебного таймера автоматически повышается только для короткого цикла и остаётся прежней для обычных многосекундных значений.

## Версия

- Расширение возможностей настроек оформлено как функциональный выпуск `3.1.0`. Формат плейлистов и пресетов не изменился.
