# Wallpaper Matrix 3.0.1

## Фирменный знак

- Добавлен единый симметричный значок Wallpaper Matrix: зелёная буква `M`, собранная из нисходящих струй кода на чёрном терминальном фоне.
- Светлые ведущие блоки направлены вниз и передают движение матричного потока.
- ICO содержит отдельные слои от `16×16` до `256×256`. Малые размеры сохраняют узнаваемый силуэт без фиолетового технического фона.
- Один и тот же знак используется исполняемым файлом, окнами операторской консоли и областью уведомлений.

## Версия

- Изменение не затрагивает D3D11-рендерер, настройки или формат пользовательских данных, поэтому выпуск оформлен как исправление `3.0.1`.
