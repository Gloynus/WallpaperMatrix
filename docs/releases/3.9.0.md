# Wallpaper Matrix 3.9.0

## Атака системы

- Атакующий поток использует только струи, родившиеся после начала перехода.
  Они честно натекают сверху по собственным настройкам скорости и не
  открываются общей геометрической маской.
- Фоновый градиент получает фору, равную времени прохождения экрана самой
  быстрой разрешённой струёй: `1 / До` в контуре **Скорость соединения**.
  При разных настройках экранов используется наибольшее такое время. Затем
  градиент проходит экран за заданное время **Захвата системы**.
- Снимок интерфейса проходит тот же конвейер анализа тонов, что и файлы
  плейлиста. Маска захвата определяет только область действия и не меняет
  правила яркости, контраста, Стабильности света или Устойчивости тени.
- До фронта Захвата остаётся виден исходный интерфейс, а новые струи текут
  поверх него. За фронтом повторно используется текущая сцена живых обоев:
  поверхность становится непрозрачной и больше не допускает появления панели
  задач, панели оператора или других окон между символами.
- Базовый и атакующий слои используют уже работающие `SharedMatrixScene`.
  Новая симуляция или второй генератор потока не создаются.

## Распространение

- Архив `WallpaperMatrix-3.9.0-portable-win-x64.zip` — самодостаточная сборка
  для Windows 10 и 11; отдельная установка .NET не требуется.
- Рядом публикуется SHA-256-сумма архива.
- Лицензия проекта — GPL-3.0-only. Сборка пока не имеет цифровой подписи
  издателя, поэтому Smart App Control может блокировать её запуск.
