# Wallpaper Matrix 3.7.4

- Запуск живых обоев и АТАКА СИСТЕМЫ теперь используют один и тот же фронт
  фона сверху вниз. Запуск занимает установленное **Время фиксации**, Атака —
  установленное время **Захвата системы**; скорость самого потока не меняется.
- Захваченный интерфейс больше не уступает плейлисту во время наплыва. Он
  остаётся целью новых струй до окончания Захвата и ещё одного полного Времени
  фиксации. После границы только новые поколения струй начинают проявлять
  текущий образ, поэтому уже напечатанные символы не меняют яркость скачком.
- **Цикл образа** переименован во **Время фиксации**.
- Контекстное меню мониторчиков получило цельный матричный фон без системного
  светлого поля слева.
- Исправлено нижнее подрезание бегунка вертикального скроллбара.
- На вкладке **Терминал** иллюстрация расположена перед собственной подсказкой,
  подписи параметров приведены к общему размеру, а названия вкладок
  Калибратора увеличены на один пункт.
