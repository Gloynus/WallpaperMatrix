# Wallpaper Matrix 3.7.11

Исправлен первый запуск «Атаки системы» после старта приложения.

- DXGI Desktop Duplication теперь подготавливается только по запросу Атаки и без ожиданий в потоке отрисовки.
- Для каждого монитора пропускаются два холодных кадра DWM; реальный отпечаток снимается после следующего обычного кадра обоев.
- Подготовка идёт по одному выходу за кадр и не зависит от установленной частоты потока.
- После получения отпечатка сеанс захвата и временные видеоресурсы освобождаются, поэтому наблюдатель экрана не остаётся работать в фоне.
- Удалены эвристическое замыкание отдельных ячеек и принудительное заполнение «почти полного» экрана: целостность отпечатка обеспечивается синхронизацией источника, а не дорисовкой результата.
- Захват больше не ждёт до 120 мс появления кадра DXGI; холодная подготовка проходит до фактического снимка.

Проверено двумя независимыми холодными запусками на топологии из четырёх физических мониторов: все четыре выхода получены, подготовка заняла 31 и 29 мс, жизненный цикл Атаки завершился штатно.
