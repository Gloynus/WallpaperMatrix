# Wallpaper Matrix 3.0.2

## Совместимость с рабочим столом Windows 11

- Исправлен порядок современной пары системных запросов, которой Explorer создаёт фоновый слой `WorkerW`: подготовка теперь всегда выполняется перед подтверждением.
- Современная композиция Windows 11 больше не принимается за обычный `SHELLDLL_DefView`. Если Explorer не предоставил настоящий фоновый слой, приложение завершает подключение с явной ошибкой вместо ложного сообщения об активном невидимом выводе.
- Диагностика теперь отдельно отмечает обнаружение современной композиции рабочего стола.

## Значок

- В выпуск встроен авторский знак Gloynus Aleos без перерисовки и изменения композиции.
- ICO содержит размеры `16`, `20`, `24`, `32`, `40`, `48`, `64`, `128` и `256` пикселей.
- Значок назначается не только исполняемому файлу, WPF-окну и области уведомлений, но и нативным окнам D3D11-композитора. Это устраняет стандартный значок у группы приложения в Диспетчере задач.

## Версия

- Изменения не затрагивают пользовательские настройки, плейлисты или формат пресетов, поэтому выпуск оформлен как исправление `3.0.2`.
