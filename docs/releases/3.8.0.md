# Wallpaper Matrix 3.8.0

## Стабильный выпуск

Wallpaper Matrix 3.8.0 завершает серию доработок 3.7 и доступен как переносимая
самодостаточная сборка для Windows 10 и 11.

### База данных и плейлисты

- Статичные обои Windows используются как нулевой образ при каждом запуске и
  возобновлении потока: изображение плейлиста не появляется мгновенно.
- Нулевой образ повторяет фактическую раскладку системных обоев, включая
  кадрирование «Заполнить».
- Недоступные файлы в плейлисте получают приглушённую красную индикацию при
  попытке чтения, а после восстановления файла строка возвращает обычный вид.

### Атака системы

- Отпечаток интерфейса снимается после подготовки DXGI Desktop Duplication,
  а не в его холодном первом кадре.
- Для каждого экрана пропускаются два кадра DWM; подготовка идёт без ожиданий
  и по одному выходу за кадр.
- Захват больше не держит наблюдатель экрана и временные видеоресурсы после
  запуска Атаки.
- Убраны эвристики, искусственно дорисовывавшие маску интерфейса. Целостность
  перехода обеспечивается синхронизацией реальных кадров Windows и обоев.

### Распространение

- Архив `WallpaperMatrix-3.8.0-portable-win-x64.zip` самодостаточен: .NET
  устанавливать отдельно не нужно.
- Рядом опубликована SHA-256-сумма архива.
- Приложение остаётся распространяемым по лицензии GPL-3.0-only.

> Открытая сборка пока не имеет цифровой подписи издателя. На системах с
> включённым Smart App Control Windows может заблокировать запуск
> неподписанного приложения.
