# Wallpaper Matrix 3.10.2

## Исправление панели оператора

- Устранено исключение `Sequence contains no elements` при первом открытии
  панели после запуска 3.10.1.
- Во время начальной загрузки редактор плейлиста корректно использует корневую
  проекцию настроек, пока список физических устройств ещё не получен.
- После получения топологии редактор автоматически работает с профилем
  выбранного монитора и сохраняет раздельные параметры изолированных Баз
  данных.
