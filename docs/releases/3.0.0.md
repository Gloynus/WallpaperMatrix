# Wallpaper Matrix 3.0.0

## Новый графический тракт

- Вывод полностью перенесён с OpenGL 3.3/WGL на Direct3D 11.
- Кадр передаётся Explorer через DirectComposition и composition swap chain. Этот путь поддерживает как обычный `WorkerW` Windows 10, так и layered/raised desktop современных сборок Windows 11.
- Симуляция потока, атлас знаков и все визуальные настройки сохранены. На видеокарту по-прежнему отправляется компактный список видимых символов, а не полноэкранное изображение через процессор.
- Все мониторы используют одну виртуальную поверхность, одно D3D11-устройство и одну копию состояния главного экрана.

## Совместимость и нагрузка

- Требования: Windows 10/11 x64 и видеокарта с уровнем возможностей D3D 10.0 или новее. Отдельные OpenGL-компоненты больше не нужны.
- Используется аппаратное D3D11-устройство, двойная flip-model буферизация и встроенный композитор Windows.
- Частота потока и пауза в играх продолжают управлять нагрузкой как прежде.
- При потере устройства или ошибке передачи кадра причина записывается в журнал вместо молчаливого зависания.

## Диагностика

- Журнал сообщает уровень возможностей D3D11, размер composition swap chain и факт подключения DirectComposition.
- Строки состояния и сообщения запуска больше не ссылаются на OpenGL 3.3.
