# Заметки о выпусках

Один файл соответствует одной версии Wallpaper Matrix. Имя файла обязано
совпадать со значением `Version` в `WallpaperMatrix.csproj`.

Штатная сборка копирует соответствующий файл в portable-пакет как
`RELEASE_NOTES.txt`. Тег `vX.Y.Z` использует тот же файл как описание выпуска
на GitHub.

Общий указатель: [CHANGELOG.md](../../CHANGELOG.md).
