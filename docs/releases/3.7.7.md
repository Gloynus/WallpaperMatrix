# Wallpaper Matrix 3.7.7

- Исправлена первопричина половинчатого бегунка в длинном плейлисте. Теперь
  минимальная длина задаётся на уровне расчёта дорожки WPF, поэтому слот и
  визуальная плашка имеют одинаковую геометрию, а оба скругления остаются
  видимыми во всех положениях.
- Шрифт вертикальной боковой рейки увеличен на один пункт.
- Шрифт вкладок Калибратора потока уменьшен на один пункт для более свободной
  компоновки названий.
- Заголовки всех основных и дочерних блоков приведены к единому размеру —
  крупнейший прежний размер увеличен ещё на один пункт.
