# Wallpaper Matrix 2.3.1

## Исправления стабильности

- Внешний просмотрщик изображения запускается вне UI-потока. Медленный ответ оболочки Windows больше не блокирует консоль и очередь команд рендера.
- При блокировке, отключении сеанса или переходе Windows в сон OpenGL-поверхность полностью закрывается. После разблокировки приложение ждёт готовность Explorer и создаёт поверхность заново; предусмотрено до четырёх попыток.
- Ручная остановка сохраняется при разблокировке и не включается автоматически.

## Windows 11 raised desktop

- Добавлено обнаружение дочернего `WorkerW` внутри `Progman`, появившегося в новых версиях Windows 11.
- В raised desktop рендер теперь встраивается непосредственно в дочерний `WorkerW`, после чего `SHELLDLL_DefView` принудительно перерисовывается и убирает статический снимок рабочего стола.
- Прежний резервный путь внутри `SHELLDLL_DefView` оставлен только как последний вариант. Фон `SysListView32` временно переводится в прозрачный режим и гарантированно восстанавливается при Stop, выходе или ошибке.
- Диагностика сообщает `surface=RaisedWorker`, дескриптор дочернего WorkerW и результат обновления слоя значков.

## OpenGL и NVIDIA

- Все мониторы объединены в одно окно-компоновщик и один контекст OpenGL 3.3. На каждый монитор назначается отдельный viewport с копией потока главного экрана.
- Окно помечается `WDA_EXCLUDEFROMCAPTURE` до встраивания в Explorer. Это исключает поверхность обоев из обычных механизмов записи Windows и уменьшает вероятность срабатывания игровых оверлеев.
- Вместо серии уведомлений NVIDIA при запуске теперь создаётся только одна графическая поверхность.
