# Wallpaper Matrix 2.3.4

## Raised desktop Windows 11

- Добавлена поддержка современной схемы Explorer с `WS_EX_NOREDIRECTIONBITMAP`: рендер создаётся как полноразмерное `WS_EX_LAYERED`-окно внутри `Progman`.
- Окно располагается в штатном Z-порядке ниже `SHELLDLL_DefView` со значками и выше вложенного `WorkerW` со статическим фоном.
- Поток занимает полные границы всех мониторов, включая пространство за панелью задач, но остаётся физически ниже значков, рамки выделения, контекстного меню и любых обычных окон.
- В реализации нет верхнего оверлея, вырезов под значки и подмены системного файла обоев.
- Z-порядок `SHELLDLL_DefView → рендер → WorkerW` периодически проверяется и восстанавливается без активации окон Explorer.
- Защита от захвата экрана сохранена, поэтому драйверные оверлеи не получают множество ложных игровых окон.

## Остановка

- В raised desktop Stop удаляет только окно рендера. Исходный `WorkerW` сразу становится видимым, поэтому Explorer не скрывается и системные обои не приходится переприменять.
- Основной `DedicatedWorker` и классический резерв `DefViewBackground` сохраняют прежнее восстановление рабочего стола.

## Диагностика

- Журнал сообщает расширенные стили `Progman` и `SHELLDLL_DefView`, результат распознавания raised desktop, выбранную поверхность `RaisedDesktop`, проверку Z-порядка и подтверждение первого непустого кадра.
- Основной `DedicatedWorker` остаётся первым вариантом. `RaisedDesktop` включается только в соответствующей топологии Windows 11; несовместимый `DefViewBackground` в ней больше не выбирается.
