# Wallpaper Matrix 3.7.8

- Автоматический обход плейлиста теперь сообщает панели о каждой недоступной
  строке: пропущенный файл сразу получает приглушённую красную индикацию без
  фонового опроса файловой системы.
- Нулевой образ Базы данных воспроизводит реальную раскладку статичных обоев
  Windows, включая смещённое вертикальное кадрирование режима «Заполнение».
- Проверка доступности изображений выполняется при чтении плейлиста и перед
  ручным открытием или проявлением, а не по секундному таймеру.
