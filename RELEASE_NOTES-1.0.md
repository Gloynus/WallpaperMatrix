# Wallpaper Matrix 1.0

Живые обои для Windows в духе операторских мониторов «Навуходоносора».

## Системные требования

- Windows 10 или Windows 11, x64
- Видеодрайвер с поддержкой OpenGL 3.3

Сборка автономная: отдельно устанавливать .NET не требуется.

## Запуск

Запустите `WallpaperMatrix.exe`. Приложение продолжает работать из области
уведомлений под зелёным значком `M`. Двойной щелчок по значку открывает
операторскую консоль.

Настройки сохраняются в:

`%LOCALAPPDATA%\WallpaperMatrix\settings.json`

## Возможности версии 1.0

- OpenGL 3.3-рендеринг символьных потоков на рабочем столе.
- Поддержка нескольких мониторов с общей симуляцией.
- Индивидуальная скорость и длина каждого потока.
- Фосфорное свечение, световой импульс и настраиваемое начертание.
- Проявление изображений исключительно символами кода.
- Автоматический подбор символов и начертаний по плотности.
- Настраиваемые стабильность света и устойчивость тени образа.
- Символьные часы `HH:mm` в восьми положениях.
- Живой предпросмотр параметров с возможностью отмены.
- Полная остановка симуляции во время полноэкранных игр.
- Работа из области уведомлений и необязательный автозапуск.
