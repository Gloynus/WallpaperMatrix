# Wallpaper Matrix 3.3.1

## АТАКА СИСТЕМЫ

- Исправлен захват интерфейса Windows: допустимая растровая операция
  `SRCCOPY | CAPTUREBLT` теперь вызывается напрямую через Win32 и не
  отклоняется проверкой перечисления `Graphics.CopyFromScreen`.
- «АТАКА СИСТЕМЫ» оформлена отдельным сворачиваемым блоком после
  «БАЗЫ ДАННЫХ».
- У блока появился собственный общий сброс. Сбросы отдельных полей сохранены,
  а системный сброс больше не меняет настройки атаки.
- Команда ручного запуска удалена из меню области уведомлений. Проверка
  осталась внутри профильного блока настроек.

## Диагностика

- Добавлена скрытая самопроверка `--validate-attack`: она проверяет D3D11-
  шейдеры и реальный снимок всего виртуального рабочего стола, не открывая
  поверхность заставки и не сохраняя изображение на диск.
