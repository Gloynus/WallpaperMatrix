# Wallpaper Matrix 3.5.0

Функциональный выпуск с переносимыми плейлистами оператора и единым
потоковым переходом.

## Переходы

- При запуске статичные обои теперь плавно растворяются под натекающим кодом,
  после чего поверхность достигает обычного непрозрачного состояния.
- «Атака системы» больше не снимает интерфейс и не преобразует его яркость в
  символы. Новые струи обычной сцены проявляют текущий образ поверх системы,
  а свободные участки постепенно переходят в цвет фона.
- Из пути атаки удалены захват экрана, промежуточная BGRA-копия и отдельная
  текстура снимка.

## Пресеты и плейлисты

- Глобальный пресет «Оператор» запоминает выбранный плейлист отдельно для
  каждого профиля монитора.
- Файлы и пути изображений по-прежнему не входят в пресет. На другом ПК
  привязка сначала ищется по устойчивому идентификатору, затем по имени.
- Если соответствующего плейлиста нет, сохраняется текущий выбор принимающего
  компьютера: переданный пресет остаётся безопасным и работоспособным.

## Автозапуск

- Явное включение автозапуска в новой копии Wallpaper Matrix передаёт ей
  единственную системную запись и удаляет дубликаты прежних версий.
- Последняя запущенная копия с сохранённой включённой галочкой получает
  автозапуск; это одинаково работает при обновлении и при откате.
- Копия с выключенной галочкой не удаляет запись другого выпуска при обычном
  запуске.
